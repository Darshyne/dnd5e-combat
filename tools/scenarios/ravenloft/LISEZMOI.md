# Scénarios du monde `ravenloft`

Ces scénarios ne s'appliquent qu'aux mondes `ravenloft` / `ravenloft-test2` (fiches de la campagne : Alara, Kaalisti, Bramo,
Sylaene, Brume vampirique, Arrigal, Loup) : dans `dnd-6`, ils se déclarent « non applicable ». Ils sont rangés ici pour ne plus
compter dans la passe complète, qui ne lit que `tools/scenarios/*.mjs`.

Les jouer, ce monde ouvert chez le MJ :

    node tools/scenario.mjs tools/scenarios/ravenloft

ou un seul : `node tools/scenario.mjs tools/scenarios/ravenloft/drain.mjs`.
